# TB025 Paradigmas de Programación, curso Essaya (FIUBA)

Trabajos prácticos de Paradigmas de Programación (TB025), FIUBA, curso de Diego Essaya, 1C2026. Grupo Paradelo-Zarate: Ezequiel Paradelo y Agustín Zarate.

| TP | Descripción | Stack |
|----|-------------|-------|
| [TP1: Tower Defense](TP1-tower-defense) | Juego Tower Defense con niveles cargados desde XML, modelo separado de la vista y principios SOLID. | Java, JavaFX, Maven |
| [TP2: Procesamiento de imágenes](TP2-procesamiento-de-imagenes) | Aplicación para cargar imágenes y aplicar una pipeline de filtros (brillo, difuminado, inversión) que se ejecutan de forma concurrente. | Clojure, JavaFX, Leiningen |

Cada carpeta tiene su propio README con las instrucciones para ejecutarlo.
