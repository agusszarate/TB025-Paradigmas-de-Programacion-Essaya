## Descripción del proyecto
Implementación de una aplicación de procesamiento de imágenes, desarrollado con el lenguaje de programación funcional Clojure y 
JavaFX para la interfaz gráfica. La aplicación permite cargar imágenes y añadir filtros (Brillo, Difuminado e Inversión) en una pipeline de filtros.
Al aplicar los filtros, estos se ejecutan de manera concurrente para que no se trabe la aplicación.

---

## Instrucciones y requisitos de ejecución
### Requisitos
Para ejecutar la aplicación, es necesario tener instalado Leiningen y Java 21 o superior.

### Ejecución
Clonar el repositorio y ubicarse en la carpeta raíz del proyecto.  
Ejecutar el comando:
```
lein run
```
